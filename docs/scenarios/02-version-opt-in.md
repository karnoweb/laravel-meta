# سناریو ۰۲ — نسخه‌بندی انتخابی

## پیش‌شرط‌ها

محصول ذخیره‌شده. کلید `price` وجود ندارد.

## مراحل

1. `price=100.00` با `versioned: true` و `type: decimal`.
2. `price=110.00` با `type: decimal` و بدون فلگ.

## ورودی

دو رشته دهدهی.

## نتیجه مورد انتظار

مقدار جاری `110.0000000000`. یک root. دو version. تاریخچه به ترتیب `100.0000000000` سپس `110.0000000000`.

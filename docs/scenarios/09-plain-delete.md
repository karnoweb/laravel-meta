# سناریو ۰۹ — حذف کلید عادی

## پیش‌شرط‌ها

کلید عادی با مقدار `null` یا `false`، و یک کلید غایب برای مقایسه.

## مراحل

1. `hasMeta` را برای null، false، و کلید غایب جدا کنید.
2. `deleteMeta` را یک بار و بار دوم صدا بزنید.

## ورودی

`null` یا `false`.

## نتیجه مورد انتظار

null و false موجودند. کلید غایب موجود نیست. حذف اول root را پاک می‌کند و true برمی‌گرداند. حذف دوم false است و ردیف history ساخته نمی‌شود.

# سناریو ۱۲ — رشته در برابر عدد

## پیش‌شرط‌ها

دو محصول.

## مراحل

1. روی مدل A مقدار `code='10'` را به‌صورت رشته بنویسید.
2. روی مدل B مقدار `code=10` را به‌صورت int بنویسید.
3. هر نوع را جدا جستجو کنید.

## ورودی

رشته `'10'` و عدد `10`.

## نتیجه مورد انتظار

جستجوی رشته فقط A را برمی‌گرداند. جستجوی int فقط B را برمی‌گرداند.

# سناریو ۱۷ — جستجوی JSON

## پیش‌شرط‌ها

دو محصول.

## مراحل

1. `tags` یکی `['vip','sale']` و دیگری `['free']`.
2. `whereMetaJsonContains('tags', 'vip')`.
3. یک شیء تودرتو را هم جستجو کنید.

## ورودی

آرایه PHP.

## نتیجه مورد انتظار

جستجوی `vip` فقط محصول اول است. در SQLite جستجوی شیء تودرتو نتیجه خالی می‌دهد، چون `json_each` آن را مثل `JSON_CONTAINS` پیدا نمی‌کند. در درایورهای دیگر همان محصول برمی‌گردد. این تفاوت در تست شاخه‌بندی شده است.

# سناریو ۲۰ — بارگذاری گروهی

## پیش‌شرط‌ها

۱۰۰ محصول. هر کدام `color` عادی و `price` نسخه‌دار دارند. قیمت جاری محصول `i` برابر `(i + 9).00` است.

## مراحل

1. `Product::query()->withMeta(['color', 'price'])->get()`.
2. روی هر مدل `getMeta('color')` و `getMeta('price')` را بخوانید.

## ورودی

۱۰۰ رنگ و ۱۰۰ قیمت decimal.

## نتیجه مورد انتظار

کوئری کل مسیر حداکثر ۳ است. خواندن بعدی صفر کوئری است. رنگ اول `c1` و قیمت آخر `109.0000000000` است.

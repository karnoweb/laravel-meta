# سناریو ۲۲ — جداسازی branch

## پیش‌شرط‌ها

Branch روشن است. دو resolver دو کلید مختلف می‌دهند. owner یکی است.

## مراحل

1. در branch A مقدار `red` را بنویسید.
2. در branch B مقدار `blue` را برای همان کلید بنویسید.
3. خواندن، جستجو، تاریخچه و حذف را در A انجام دهید.

## ورودی

یک owner و دو branch key.

## نتیجه مورد انتظار

عملیات A مقدار B را نشان نمی‌دهد و آن را تغییر نمی‌دهد. حذف A فقط root همان branch را برمی‌دارد.
